## 2. 사이드바 라디오 버튼 변경

### 2.1 변경 목적

**문제점**:
- 기존: 체크박스 방식으로 여러 카테고리 동시 선택 가능
- EDM 문서활용과 대사우 Assistant를 동시에 선택하면 혼란 발생

**해결책**:
- 라디오 버튼 방식으로 변경하여 한 번에 하나의 카테고리만 선택 가능

### 2.2 파일 수정

**파일**: `/src/lib/components/layout/RightSidebar.svelte`

#### 2.2.1 로직 변경

**Before (체크박스 - 다중 선택)**:
```javascript
const toggleCategory = (displayCategory: typeof displayCategories[0]) => {
    const { actualIds } = displayCategory;
    const allSelected = actualIds.every(id => $selectedCategories.includes(id));

    if (allSelected) {
        // 선택 해제: 해당 카테고리만 제거
        selectedCategories.update((current) =>
            current.filter(id => !actualIds.includes(id))
        );
    } else {
        // 선택: 기존 선택에 추가
        selectedCategories.update((current) => {
            const newIds = actualIds.filter(id => !current.includes(id));
            return [...current, ...newIds];
        });
    }
};
```

**After (라디오 버튼 - 단일 선택)**:
```javascript
const toggleCategory = (displayCategory: typeof displayCategories[0]) => {
    const { actualIds } = displayCategory;
    const allSelected = actualIds.every(id => $selectedCategories.includes(id));

    if (allSelected) {
        // 이미 선택된 카테고리 클릭 → 선택 해제
        selectedCategories.set([]);
    } else {
        // 다른 카테고리 클릭 → 기존 선택 모두 해제하고 새로 선택
        selectedCategories.set(actualIds);
    }
};
```

**핵심 차이**:
- `update()` → `set()`: 기존 값에 추가하는 것이 아니라 완전히 교체
- 결과: 한 번에 하나의 카테고리만 선택 가능

#### 2.2.2 UI 변경

**Before (체크박스 스타일)**:
```svelte
<div class="w-5 h-5 rounded border-2 border-gray-400 dark:border-gray-500
     flex items-center justify-center
     {isDisplayCategorySelected(category)
         ? 'bg-blue-500 border-blue-500'
         : 'bg-transparent'}">
    {#if isDisplayCategorySelected(category)}
        <!-- 체크마크 SVG -->
        <svg class="w-3 h-3 text-white" viewBox="0 0 20 20" fill="currentColor">
            <path d="M16.707 5.293a1 1 0 010 1.414l-8 8a1 1 0 01-1.414 0l-4-4..." />
        </svg>
    {/if}
</div>
```

**After (라디오 버튼 스타일)**:
```svelte
<div class="w-5 h-5 rounded-full border-2 border-gray-400 dark:border-gray-500
     flex items-center justify-center
     {isDisplayCategorySelected(category)
         ? 'bg-blue-500 border-blue-500'
         : 'bg-transparent'}">
    {#if isDisplayCategorySelected(category)}
        <!-- 작은 원 -->
        <div class="w-2.5 h-2.5 rounded-full bg-white"
             transition:fade={{duration: 150}}>
        </div>
    {/if}
</div>
```

**시각적 차이**:
- `rounded` → `rounded-full`: 사각형 → 원형
- 체크마크 SVG → 작은 흰색 원
- 라디오 버튼의 표준 UI 패턴 적용

#### 2.2.3 상태 메시지 변경

**Before**:
```svelte
{#if $selectedCategories.length > 0}
    <p class="text-xs text-gray-600 dark:text-gray-400 mt-2">
        {$selectedCategories.length}개 카테고리 선택됨
    </p>
{/if}
```

**After**:
```svelte
{#if $selectedCategories.length > 0}
    {@const selectedDisplayCat = displayCategories.find(cat =>
        cat.actualIds.some(id => $selectedCategories.includes(id))
    )}
    {#if selectedDisplayCat}
        <p class="text-xs text-gray-600 dark:text-gray-400 mt-2">
            선택됨: {selectedDisplayCat.name}
        </p>
    {/if}
{/if}
```

**개선점**:
- "2개 카테고리 선택됨" → "선택됨: EDM 문서활용"
- 더 명확한 정보 제공

### 2.3 영향 분석

**긍정적 영향**:
- ✅ 사용자 혼란 감소 (한 번에 하나의 컨텍스트만)
- ✅ 명확한 UI 패턴 (라디오 버튼 = 단일 선택)
- ✅ 모델 자동 선택 로직 단순화

**주의사항**:
- 사용자가 여러 카테고리를 동시에 사용하고 싶어할 수 있음
- 향후 피드백에 따라 탭 방식으로 변경 가능

## 4. 비활성화 처리 구현

### 4.1 3단계 보호 메커니즘

준비중 기능에 대해 3단계 보호 장치를 구현했습니다:

1. **CSS 레벨**: `pointer-events-none` (클릭 이벤트 완전 차단)
2. **HTML 레벨**: `disabled` 속성 (버튼 비활성화)
3. **JavaScript 레벨**: `comingSoon` 체크 후 토스트 메시지

### 4.2 카드 컨테이너 스타일

**파일**: `/src/lib/components/chat/Chat.svelte` (3664번 라인)

```svelte
<div
    class="{category.comingSoon
        ? 'bg-gray-100 dark:bg-gray-800/60 rounded-xl shadow-md transition-all duration-300 overflow-hidden border-2 border-gray-300 dark:border-gray-600 opacity-40 pointer-events-none cursor-not-allowed'
        : 'bg-white dark:bg-gray-800 rounded-xl shadow-lg hover:shadow-xl transition-all duration-300 overflow-hidden border border-gray-200 dark:border-gray-700'}"
>
    <!-- 카드 내용 -->
</div>
```

**준비중 상태 스타일** (`comingSoon: true`):
- `bg-gray-100 dark:bg-gray-800/60`: 회색 배경
- `opacity-40`: 40% 투명도 (흐릿하게)
- `pointer-events-none`: 모든 클릭 이벤트 차단
- `cursor-not-allowed`: 금지 마크 커서 (🚫)
- `border-2 border-gray-300`: 두꺼운 회색 테두리

**활성 상태 스타일** (`comingSoon: false` 또는 없음):
- `bg-white dark:bg-gray-800`: 흰색 배경
- `hover:shadow-xl`: 호버 시 그림자 효과
- `border border-gray-200`: 얇은 테두리

### 4.3 버튼 비활성화

**파일**: `/src/lib/components/chat/Chat.svelte` (3734번 라인)

```svelte
<button
    class="w-full text-left px-3 py-2 text-sm transition-colors border rounded-lg
           {category.comingSoon
               ? 'bg-gray-100 dark:bg-gray-800 border-gray-300 dark:border-gray-700 cursor-not-allowed opacity-40 pointer-events-none'
               : 'bg-gray-50 dark:bg-gray-700 hover:bg-blue-50 dark:hover:bg-blue-900/30 border-gray-200 dark:border-gray-600 hover:border-blue-300 dark:hover:border-blue-700'}"
    disabled={category.comingSoon}
    on:click={async () => {
        // JavaScript 레벨 체크
        if (category.comingSoon) {
            toast.error('🚧 아직 준비중입니다');
            return;
        }

        // 정상 동작
        // ...
    }}
>
    <div class="text-sm {category.comingSoon ? 'text-gray-500 dark:text-gray-400' : 'text-gray-700 dark:text-gray-300'} line-clamp-2">
        {sample}
    </div>
</button>
```

**3단계 보호**:
1. `pointer-events-none` (CSS): 클릭 불가
2. `disabled={category.comingSoon}` (HTML): 버튼 비활성화
3. `if (category.comingSoon) { toast.error(...); return; }` (JS): 혹시라도 클릭되면 토스트 메시지

## 5. 외부 모델 필터링

### 5.1 변경 목적

**문제점**:
- 사용자가 모델 선택 드롭다운에서 외부 모델(external_llm)을 선택할 수 있음
- 외부 모델은 아직 준비되지 않았거나 사용 불가

**해결책**:
- 모델 목록에서 외부 모델을 필터링하여 선택 불가하게 만듦

### 5.2 파일 수정

**파일**: `/src/lib/components/chat/Chat.svelte` (316번 라인)

#### 5.2.1 모델 필터링 로직

**Before** (모든 모델 표시):
```javascript
const res = await getModels(localStorage.token);

if (res) {
    const allModels = res
        .filter((m) => m)
        .map((m) => ({ name: m.name, id: m.id, info: m }));

    // 모든 모델을 스토어에 저장
    models.set(allModels);
}
```

**After** (내부 모델만 표시):
```javascript
const res = await getModels(localStorage.token);

if (res) {
    const allModels = res
        .filter((m) => m)
        .map((m) => ({ name: m.name, id: m.id, info: m }));

    // 내부 모델만 필터링하여 저장
    models.set(allModels.filter(m => getModelType(m) === 'internal'));
}
```

#### 5.2.2 getModelType 함수

```javascript
function getModelType(model: any): 'internal' | 'external' {
    if (!model) return 'internal';

    const modelId = model.id || '';
    const modelName = model.name || '';

    // 외부 모델 패턴
    const externalPatterns = [
        'external_llm',
        'external-llm',
        'openai:',
        'anthropic:',
        'google:',
        'cohere:'
    ];

    const isExternal = externalPatterns.some(pattern =>
        modelId.toLowerCase().includes(pattern) ||
        modelName.toLowerCase().includes(pattern)
    );

    return isExternal ? 'external' : 'internal';
}
```

### 5.3 영향 분석

**긍정적 영향**:
- ✅ 사용자가 작동하지 않는 모델을 선택하지 못함
- ✅ 혼란 감소
- ✅ 내부 모델에 집중

**주의사항**:
- 향후 외부 모델을 활성화하려면 이 필터를 제거해야 함
- 또는 `comingSoon` 플래그를 모델에도 적용하여 선택적 비활성화 가능

### 5.4 외부정보 검색 모델 섹션 제거

**파일**: `/src/lib/components/chat/Chat.svelte` (3787-3861번 라인 삭제)

## 6. Submit 버튼 비활성화

### 6.1 변경 목적

### 6.2 Chat.svelte 수정

**파일**: `/src/lib/components/chat/MessageInput.svelte`

#### 6.3.1 Prop 추가

#### 6.3.2 Submit 버튼 수정

**Before**:
```svelte
<button
    id="send-message-button"
    class="{!(prompt === '' && files.length === 0)
        ? 'text-gray-900 dark:text-white hover:text-black dark:hover:text-gray-200'
        : 'text-gray-400 dark:text-gray-600'} transition rounded-full p-1.5 self-center"
```

**After**:

```svelte
    <svg>...</svg>
```

**변경 사항**:
- `disabled`: `prompt === ''` → `submitDisabled || (prompt === '')`
- `class`: 스타일 조건에도 `submitDisabled` 추가
